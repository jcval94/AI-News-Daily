## Changes and boundaries

1. The hardened production factual judge now receives the exact selected Narrative Memory records it previously omitted, alongside the script, source summaries, ledger and supplemental excerpts. Only verified historical claims are permissible; limits and uncertainties still apply. Factual corrections must identify actual offending prose rather than punish legitimate explicitly conditional reasoning. Attention evaluation no longer asks the writer to do the deterministic production layer's subscription CTA. No numerical threshold, retry cap, source coverage, approval rule, provider, or model was changed.
2. `pipeline/source_evidence.py` performs best-effort public HTML retrieval for explicitly allowlisted article paths (at most eight selected URLs; no redirects, credentials, or arbitrary fetches; bounded response size and timeouts). It extracts visible abstract/article passages, with a 1,500-character excerpt limit, and supplies them only to relevant factual stages. No new source claim may be added to the accepted ledger just because an excerpt contains it. A mismatch triggers omission or explicit uncertainty. Unavailable retrieval is recorded rather than called verification. `source_evidence.json` records per-item identity, retrieval status, source URL, response/excerpt hashes and retrieval scope, not article prose. It is preserved and summarized by `run_report.json`. Locally the default is `off`; production sets `retrieve`. This is not full-article retrieval or independent corroboration.
3. The isolated Notebook ending schema rejects missing required outcome references or wrong ending order before expensive whole-script repair. The ending receives the exact required historical claim indices/text; the factual judge must still establish that the prose actually supports those references. Experimental outputs remain non-publishable.
4. After a daily handoff is validated and its move to `processed/` read back successfully, the bridge can wake the next oldest exact daily handoff. The existing per-file attempt budget and cooldown remain, and other active runs suppress wakeups. The post-ack report exposes queue size and oldest age; it never marks an unprocessed file published. No extra scheduled research, polling frequency, or publication authority has been added. Fix the controlled-outcome summary's shell quoting to avoid interpreting `script_not_approved` as a command.
